# Память проекта (локально)

## Learned Workspace Facts

- **Telegram / изоляция:** мульти-клиент (канал и токен из БД / онбординга) и легаси (`TELEGRAM_CHANNEL_ID` в `.env`) — разные системы. Fallback в `.env`-канал только при `clientId === "default"` в задаче очереди; пустой `clientId` — без fallback. У клиента без `telegramChannelId` в БД — ошибка, не пост в общий канал.
- **Дзен:** приложение не публикует в Дзен напрямую; текст уходит в Telegram-канал клиента, зеркалирование в Дзен — через синхробот (`@zen_sync_bot`) на стороне клиента; картинки в Дзен при необходимости дорабатываются вручную.
- **Интервал публикации:** при `Publish skipped` / `interval_wait` фактическое время поста в Telegram может сдвигаться относительно «круглого» слота на несколько минут.
- **Онбординг и аудио:** content-factory один раз скачивает файл по HTTPS-URL, конвертирует и транскрибирует; временные файлы на сервисе удаляются, URL аудио в БД не сохраняется.

## Learned User Preferences

- **Контракт веб-онбординга для интеграций:** пропущенный вопрос в теле запроса отражается как `null` в полях ответа (текст/аудио), а не пустая строка.
- **Хранение загрузок у клиента:** после успешного ответа `201` на онбординг загруженные аудиофайлы на стороне клиента можно удалять — повторных обращений к URL со стороны сервиса не будет.

## Content-factory (актуально, 2026)

Подробный список правок: [content-factory/docs/ИЗМЕНЕНИЯ_2026-03.md](content-factory/docs/ИЗМЕНЕНИЯ_2026-03.md).

- **Google Sheets:** у первого листа `sheetId = 0`. Нельзя проверять лист через `!sheetId` — только `sheetId == null` / `undefined`.
- **Цепочка текста → картинка:** после генерации текста статус — `Текст готов, ждём картинку`; картинка генерируется отдельным пайплайном, затем — `Готово к проверке` (или `Одобрено на публикацию` без модерации). Превью без автоматической вставки UTM в тело; UTM в отдельной колонке.
- **Семантика:** при сбое Wordstat — деградация; при несовпадении AI-ключей с Wordstat — в колонку D ключи из AI, не «левый» один НЧ из Wordstat.
- **Telegram публикация:** `403 bot is not a member of the channel` — бот не в канале или неверный канал в настройках клиента.
- **OpenRouter:** пустой или `PENDING` ключ клиента → используется глобальный ключ из конфига.
