# Изменения content-factory (март 2026)

Краткий журнал доработок для онбординга и продакшена.

## Google Sheets: `sheetId === 0`

Первый лист в таблице всегда имеет числовой `sheetId = 0`. Проверка вида `if (!sheet?.properties?.sheetId)` в JS считает `0` ложным значением и ложно сообщала «лист не найден». Исправлено на `sheet?.properties?.sheetId == null` в `src/sheets/client.ts` и `src/sheets/templateCopier.ts`.

## Семантика (Wordstat + заголовки)

- **Wordstat:** при ошибке API возвращается пустой список, пайплайн не падает целиком.
- **Фильтр КЗ:** если после фильтра по Wordstat не осталось совпадений с AI-ключами, используются **ключи из ответа AI**, а не подстановка сырого Wordstat (избегает мусора вроде одного нерелевантного НЧ).
- **insertTaskRows:** ошибка вставки строк логируется как предупреждение, статус «Ошибка» не выставляется из-за сбоя вставки (первая строка уже сохранена).
- **Парсер заголовков** (`src/ai/headlines.ts`): снятие нумерации `1.`, markdown `**`, кавычек; снятие `[` `]` у списка КЗ; дефолтный промпт без привязки к «питомнику» и без скобок в формате ответа.
- **Логирование:** `writeKeywords` пишет в лог строку, число ключей и превью — для отладки колонки D.
- **Пустой Wordstat (`keywordList === []`):** в промпт в `{keywords}` подставляется явная инструкция модели самой сгенерировать 5–10 поисковых запросов по теме основного КС, а не одна фраза (иначе модель часто не выводит блоки `КЗ:` → парсер находит один заголовок и почти пустая колонка D).

## Данные в таблице клиента (опечатка в КС)

Если в столбце A указано **«горетнзия метельчатая»** вместо **«гортензия метельчатая»**, Wordstat возвращает пустой список НЧ. Оператору:

1. Открыть лист **«Задания»** в таблице клиента (пример ID из логов: `1yM0-7hHT3Cf2JzzN6PLGSQykZ7mzK1Wzz4ZtF91qHaQ`).
2. Найти строки с опечаткой в столбце A и заменить на **гортензия метельчатая**.
3. Для строк, которые нужно перегенерировать по семантике, выставить статус **«Новое»** (после деплоя фикса в `headlines.ts`).

## Генерация текста и превью

- После текста статус **`Текст готов, ждём картинку`** (не сразу «Готово к проверке»), чтобы сработала очередь картинок.
- В превью **не вставляются** UTM-ссылки через `insertCatalogLinks`; UTM остаётся в колонке UTM-метки.
- Из блока фактов граундинга **вырезаются URL** перед черновиком; хосты источников по-прежнему попадают в колонку «Источники».

## Генерация картинки

Пайплайн `imageGeneration.ts` обрабатывает строки со статусом `Текст готов, ждём картинку`. После успеха — статус `Готово к проверке` или `Одобрено на публикацию` (зависит от модерации).

## Telegram: типичная ошибка публикации

`403 Forbidden: bot is not a member of the channel chat` — бот не добавлен в канал как администратор (или неверный `telegramChannelId` в БД/таблице). Нужно добавить бота в канал и проверить ID канала.

## Прочее (из сессии)

- OpenRouter: если у клиента ключ `PENDING` или пустой, подставляется глобальный ключ из конфига.
- Онбординг: `isActive: true` при создании клиента (устранён гоночный сценарий с выключением из админ-листа).
- Лого: обработка через allowlist, опционально remove.bg, синхронизация Telegram-канала и лого в таблице.
